04 · Enterprise risk

Assess the whole agentic system.

The critical unit of governance is not the model alone. It is the model plus instructions, connected data, identity, permissions, tools, runtime, approval points, logs and recovery procedures.

Excessive agency

HIGH

Errors become consequential when a model can act across systems or make irreversible changes.

  • Default to read-only and least privilege
  • Require approval for external, financial or destructive actions
  • Use bounded workflows with explicit stop conditions

Prompt injection and tool misuse

HIGH

Browsed or retrieved content can attempt to steer the agent away from authorised intent.

  • Treat external content as untrusted data
  • Validate tool arguments and destinations
  • Separate control instructions from retrieved content

Data disclosure

HIGH

Large context and connected search can aggregate more sensitive information than a human operator would ordinarily see.

  • Apply identity-aware retrieval and classification
  • Minimise context and redact secrets
  • Test cross-tenant and cross-user boundaries

Reliability and evidence

MEDIUM

Vendor benchmarks do not remove the need for task-specific accuracy, hand-off and resilience testing.

  • Build a representative evaluation set
  • Measure intervention and recovery rates
  • Retain audit-ready traces and artefacts
05 · Recommended posture

Observe. Constrain. Scale.

For an engineering organisation, the best first deployment is a valuable but reversible workflow where tool access can be tightly controlled and outcomes can be objectively reviewed.

01

Observe

  • Select one workflow with a human baseline
  • Run in shadow or recommendation-only mode
  • Measure quality, latency, cost and interventions
  • Capture complete traces and failure taxonomy
02

Constrain

  • Grant narrow, task-specific permissions
  • Make all changes reversible
  • Add policy gates and human approvals
  • Red-team injection, leakage and scope escape
03

Scale

  • Expand only after evidence-led review
  • Version prompts, policies and model snapshots
  • Monitor drift, incidents and unit economics
  • Maintain fallback and rapid revocation paths
